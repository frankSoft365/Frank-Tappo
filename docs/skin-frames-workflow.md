# 皮肤帧手工流程清单 v0

目的：把「从一张已验收的底帧延伸出其余五态」的做法固化成可重复步骤。v0 由莫宁（第二角色）闭眼帧的实操得出；将来 GUI「状态工坊」只把这个流程搬进界面，不发明新规则。

## 0. 不变量（先读）

- 底板帧 = 唯一构图事实源。其余帧只许**局部补丁**：从底板出发只改变化区域，区域外 0 像素。
- 变化区域 = 帧间 diff 的实测外接框，事后回填 manifest；禁止先画框再凑像素。
- 像素风硬约束：只用角色已有色族，无渐变、无抗锯齿。
- 槽位与橙模板的几何契约见 `docs/skin-manifest.md`；本文件只给操作顺序。

## 1. 步骤

### S0 底帧拟合（一次性）

- 输入：角色源图（莫宁 300×300，`/tmp/tappo-skin-v1/moning-src2.png`）。
- 参数：等比 `k = 画布宽 / 源宽` 左右撑满；锚点 = 衣领滚边上沿 → 模板 row 126（零脖子）。
- 莫宁现值：`k = 197/300 = 0.656667`，`off = 126 − 239k = −30.9433`，`dest_row = src_row×k + off`。
- 操作：`moningframes <src> 197 164 <outdir>`（Swift + CGContext，`.interpolationQuality = .none`）。
- 产出：`default.png`（up|open）。
- 门：197×164；内容 bbox rows 0..153 × cols 0..196；α=255 共 30338 px。
- 已知代价：头顶光环上裁 29 行、0.657 非整数缩放抽掉个别 1px 线（拍板项③）。

### S1 量基准

- 眼：`axisscan` + `colormap` 取虹膜 bbox 与眼底。莫宁实测 rows 96..109 × cols 95..118（外角粉晕延伸到 c121，矩形区域必须盖住）。
- 闭眼线位置 = 眼底往上 1~4 行（橙样板：杠在眼的下三分之一）。
- 设计参照槽（折中模板）：eyes 73..116 × 48..128。

### S2 学样板画法（橙 = 唯一已验收的闭眼）

`default-eyes-closed.png` 实测解剖：

- 整眼清成脸色：虹膜、眼白高光、下眼影全清。
- 一条深色横杠：色 = **刘海暗色**（#3d1615），不是脸线色；顶线整宽 1px，向**外眼角**逐行加厚 1px 台阶，共 4~5 行；位于眼下三分之一。
- 杠上方 1px 高光（比脸色亮一档 #fefbf5）；杠下方 1px 软影（暖粉灰 #e7d3cc）。

### S3 掩码重绘（本次实操核心）

失败教训：矩形平涂会**切穿压在前面的发丝**（莫宁：左上垂下的刘海尖 c95..97、右侧分叉发绺 c116/c122、淡紫绺边），并在脸色渐变处留下硬边方块。

操作顺序：

1. 圈定重绘区（eye bbox 外扩 0~2 px）。
2. **保护色族**：区内凡头发色族的像素一律跳过（本例：藏青 #464b57、青影 #3c5157、淡紫 #99a9c9/#a4b2d1，容差 ±12~14）。
3. 填充色 = **局部脸色**，不是角色全身主色——抄样板颜色前先量邻域（莫宁眼周是冷白 #fefbfa；橙脸才是奶油 #fef2ec）。
4. 按行铺：眼睑白 + 阶梯横杠；杠下保留角色原有的下眼影/腮红行当软影（莫宁保留了 row 109 起的腮红）。
5. 迭代只看两档：10× 修形状、2× 断接缝。1× 看图不算证据。

莫宁 v0 参数：睑 rows 96..104，杠 rows 105..108（105 全宽 c98..117 → 108 收窄到 c104），保护 c95..97 与 c116+ 发族。

### S4 校验门（每帧必过）

- diff：重载写出的两张 PNG，按 α≥128 口径逐像素比 → 记录 px 数 + bbox + 槽外计数（必须 0）。
- alpha 统计两帧相等（轮廓没动）。
- 记录 md5 + sha256（将来进 manifest/lock）。
- 过门前不许称"已出"。

### S5 手部状态（莫宁阻塞点，待拍板）

她的底姿势 = 左臂抬起横在胸前（rows ~106..123 × cols ~39..123），与橙"双手收身侧"不同。三选一：

- **A 原位拍**：抬着的手就地落一下。handL 槽改 110..129 × ~90..128，eyes 槽收为 73..109。不新画臂，代价 = 折中模板再改一次。
- **B 整臂落下**：手落到模板下部槽（118..163 × 83..118），槽需扩到整臂，动已验收的槽边界。
- **C 重画底帧**：底帧改成橙式收手姿势，槽全按折中模板。最贴模板，但要重画她的左臂。

关联：她的右手（橙的 right 态）原本垂下，需要新画（拍板项④）。

### S6 落 manifest

- regions 回填**实测** bbox（当前两帧 eyes = 96..108 × 98..121）。实测槽是契约口径，与折中模板槽（设计口径）同存。
- 跑 `src-tauri/tests/skin_manifest.rs`。整批仍红（54 fail，2026-11-26 记录），单帧以 S4 为准。

## 4. 踩坑记录

- 矩形平涂切发丝（→ S3 掩码方案）。
- 抄样板颜色不量邻域（奶油 vs 冷白）。
- PNG/CG 行序（→ §3）。
- 非整数缩放抽 1px 线：修形以帧内实测为准，不拿源图坐标想象。
- "看起来对"不算数，一切以 S4 记录为准。
